# study note 작성 규칙

## 자료 처리

- 강의자료가 PDF이면 쪽 번호를 슬라이드 번호로 쓴다.
- 표지, 간지, 강사 소개, 성적·강의계획 같은 운영 정보는 넣지 않는다. (단, 표지·목차 위의 손필기는 그 장 머리에 [필기]로 넣는다.)
- 내용이 완전히 같은 중복 슬라이드는 한 번만 정리하고, 번호 대응을 한 줄로 적는다.
- 여러 슬라이드에 반복해서 겹쳐 있는 문구(워터마크·오버레이)는 본문에서 빼고, 그 대분류에 [원문 확인]과 함께 한 번만 적는다.

## 번역 (영어 자료)

- 본문은 한국어로 번역해 쓰고 용어는 번역어 뒤 괄호에 영어를 함께 적는다: 수요곡선(Demand Curve), 만기수익률(Yield to Maturity, YTM).
- 절 제목도 같은 방식: `### 3.2.1 수요곡선 (Demand Curve)`.
- 그래프 속 축·곡선 이름은 번역 + 원래 기호를 함께 적는다(가로축 채권 수량 B, 세로축 채권 가격 P).

## 이미지·그래프

- 사진·지도·도면·**그래프**처럼 그림 자체가 내용인 것은 그림으로 넣는다. images/ 폴더에 해당 영역만 잘라 저장하고 마크다운 문법 `![]()`으로 삽입한다. (HTML `<img>` 태그는 사용자의 편집기가 지운 적이 있다.)
  - 사진: 폭 240px·높이 180px 안팎이면 충분하다.
  - **그래프·도식·손필기 그림: 고해상도(200~300dpi)로 잘라 단 너비에 맞게 넣는다.** 그래프가 많은 과목은 그래프가 곧 시험 문제라서, 작게 넣으면 프린트에서 읽을 수 없다.
- 그림 아래에는 그림 속 정보를 글로 모두 옮긴다: 축 이름, 곡선 이름, 이동 방향(B₁ᵈ → B₂ᵈ 오른쪽), 균형점 변화, 숫자, 손글씨. Ctrl+F 검색과 프린트 가독성 때문이다. 자료에 적힌 것만 쓰고 해석하지 않는다.
- 이미지 속 글자(법령, 표, 공식, 도식 설명)는 텍스트나 표로 옮긴다. 긴 조문은 "조문 번호(제목) + 핵심 문구" 표로.
- 배경 그림 위에 글자만 있는 장표는 이미지로 넣지 않고 텍스트로 담는다.

## 손필기 ([필기])

- 강의자료 위 손필기는 [필기]로 표시해 그 내용이 설명하는 위치에 넣는다. PDF에 합쳐진 손필기는 텍스트 추출에 안 나오므로 쪽 이미지를 확대해 읽는다.
- **작은 글씨 필기도 빠짐없이 본문 글로 옮긴다.** 그림 속에 작게 남겨 두면 프린트했을 때 안 보인다. 손필기 전용 쪽(빈 쪽에 쓴 것)은 그림 전체를 넣고 내용을 [필기] 줄로 모두 옮긴다.
- 판독이 불확실하면 `[원문 확인: '…'로 보임]`. 추측해서 메우지 않는다.
- 녹음으로 애매한 필기가 분명해지면(필기는 교수 말을 받아 적은 것이므로) 고쳐도 된다. 고친 줄 끝에 `(녹음으로 수정: 파일 분:초)`를 달고, 원래 판독은 보고 표에 남긴다.
- **필기 위치 판단**: 필기는 손이 닿는 여백에 적힐 뿐이라, 적힌 슬라이드와 내용 주제가 다를 수 있다(예: 할인채 슬라이드 여백에 현재가치 설명, 균형 그래프 위에 곡선 이동 요인). 필기마다 ① 적힌 PDF 쪽 ② 내용 주제 ③ 녹음에서 같은 말을 한 시각을 대조해, 주제·녹음이 가리키는 절에 넣는다.
  - 옮긴 줄에는 `(위치 옮김: Ch○ ○쪽 ○○ 슬라이드 여백 — 내용이 ○○라 이 절로 옮김)`을 달고, 원래 자리에 그림이 있으면 "이 그림 위 ○○ 필기 → ○절로 옮김" 안내 줄을 남긴다.
  - 같은 필기에 딸린 [강의] 줄도 함께 옮긴다. 큰 손필기 쪽에서 일부만 옮길 때는 그 부분을 따로 잘라 새 위치에 그림으로도 넣는다.
  - 슬라이드 순서와 녹음 순서가 모두 맞는 필기는 옮기지 않는다. 옮긴 것과 그대로 둔 것을 보고 표에 적는다.

## 판서 ([판서])

- 판서 사진은 칠판 부분만 잘라 넣는다(사람이 나오지 않게). 내용(식, 그래프 축·곡선, 숫자)은 [판서] 줄로 옮긴다. 필기나 녹음과 같은 내용이면 서로 가리킨다("판서 IMG_4439와 같은 식").

## 수식

- 수식은 처음부터 LaTeX로 쓴다. 문장 속은 `$…$`, 따로 세울 식은 불릿 한 줄 전체를 `$$…$$`로.
  - 분수는 `\frac{분자}{분모}`로 쓴다(`a/b` 금지). 분수가 있는 식은 되도록 `$$…$$` 줄로 세운다 — 문장 속 분수는 작아진다.
  - 거듭제곱·첨자는 `(1+i)^{n}`, `P_{t+1}`, `\pi^e`처럼 쓴다. `e*2`, `x^2`를 그냥 글자로 두지 않는다. 유니코드 첨자(ⁿ, ₜ)도 본문에서는 LaTeX로 바꾼다.
  - 그리스 문자·기호: `\pi`, `\beta`, `\varepsilon`, `\times`, `\approx`, `\Rightarrow`. 한글은 `\text{표면이자율}`.
  - 천 단위 쉼표는 `1{,}000`, 퍼센트는 `\%`.
- **통화 기호 `$`는 `\$`로 쓴다**(예: `\$1,000`). 그대로 두면 수식으로 잘못 읽힌다.
- Word 변환에서 무너지는 표기(`\underbrace`, `\underset{\downarrow}{i}`)는 변환 스크립트가 바꿔 주지만, 새 표기를 쓰면 Word PDF로 한 번 확인한다.
- `$`가 짝이 안 맞거나, 닫는 `$` 바로 뒤에 숫자가 붙으면 VS Code 미리보기에서 깨진다. `scripts/mathcheck.py`로 전체를 확인한다.

## 형식

- 위계: `#` 대분류 > `##` 중분류 > `###` 소분류, 번호는 1. / 1.1 / 1.1.1 (`#### Case 1`처럼 번호 없는 4단계는 허용)
- 불릿을 최대한 활용한다. 불릿은 3단계까지만.
- 원문에 표가 있으면 표로 유지하되, 더 나은 정리 방안이 있으면 가시성 있게 정리한다.
- 핵심 용어는 **굵게**.

## 디자인 요소 금지 (.md 원본)

- 원본은 순수 마크다운(.md). HTML 태그, 색상, 글꼴 지정을 쓰지 않는다. 색은 Word 사본·웹 페이지에서 표시를 보고 스크립트가 입힌다.
- 강조는 **굵게**와 형광펜 표시(`==키워드==`, `==분홍:키워드==`, `==파랑:키워드==`)만.
- 구분선(`---`)은 대분류 사이에만.

## 형광펜 표시

| 용도 | .md 표시 |
| --- | --- |
| 매우 중요한 강조 내용 | `==키워드==` (노랑) |
| 헷갈리기 쉬운 내용 | `==분홍:키워드==` |
| 분홍 내용의 역접·반대 개념 | `==파랑:키워드==` |

- 키워드 중심으로 칠한다. 한 문단에 1~2곳까지만.
- 파랑은 같은 절 안에 짝이 되는 분홍이 있을 때만 쓴다.

## 녹음 자료 규칙

- 녹음에서 온 내용은 [강의] 표시. 타임스탬프는 `(3주차 1:09:15~1:12:28)`처럼 파일·구간을 적는다(클로바노트처럼 문단 시작 시각만 있으면 그 시각).
- 녹음 내용이 강의자료와 다르면 강의자료를 우선하고 [확인 필요]로 표시한다.
- 받아쓰기 오류로 보이는 용어는 `[확인 필요: 받아쓰기 '원래 표기']`. 명백한 단순 오타만 바로잡고 보고 표에 남긴다.
- 잡담·출석·공지는 넣지 않는다. 시험 형식·범위 공지는 따로 보고한다.
- 녹음 전 구간이 노트 어딘가에 반영되었는지 구간 대응표로 점검한다.

## 녹음 반영 위치

- 기존 목차의 맞는 위치에 넣는다. 새 대분류는 만들지 않는다. 맞는 위치가 없으면 보고 목록에 적는다.
- 다른 강의 내용을 설명한 녹음은 그 내용의 위치에: (N강 복습) / (N강 강의).
- 강의자료에 없는 설명은 (자료에 없음)을 붙이고 보고에도 적는다.
- 슬라이드의 질문을 강의에서 답하면 그 답을 해당 위치 바로 아래에 둔다.

## 시험 대비 표시

- 교수 강조("중요하다", "시험에 나온다", "되게 중요한" 등)는 [강의] 뒤에 (중요)를 붙이고 그 말을 따옴표로 적는다.
- "다 외울 필요는 없다"처럼 비중을 낮춘 말도 그대로 적는다.
- 시험 범위 밖 절은 제목에 (시험범위 밖)을 붙이고, 범위 근거(필기·녹음)를 노트 머리에 적는다.

## 표시 요약 (Word·웹 색과 연결됨)

| 표시 | 뜻 |
| --- | --- |
| 표시 없음 | 강의자료 내용 |
| [필기] / [판서] | 강의자료 위 손필기 / 판서 사진 |
| [강의] | 강의 중 설명 |
| [강의] … (자료에 없음) | 강의에서만 언급한 추가 내용 |
| [강의] (중요) | 교수가 강조한 내용 |
| [풀이] | 문제풀이 때 덧붙인 내용 |
| [원문 확인] | 자료가 잘리거나 불명확함 |
| [확인 필요] | 자료와 녹음이 다르거나 받아쓰기가 불확실함 |

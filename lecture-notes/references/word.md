# Word 사본 (.docx)

## 만들기

- .md를 완성한 뒤 같은 이름의 .docx를 만든다(노트·가이드·모의고사). 원본 .md는 그대로 둔다. .md를 고치면 .docx도 다시 만든다.
- 변환: 수식이 있으면 `md2docx_math.py`, 없으면 `md2docx.py` (둘 다 같은 색·형광펜·불릿 규칙).
  - `python -I <skill>/scripts/md2docx_math.py "{강의명}_{범위}_study note.md" "{강의명}_{범위}_study note.docx"`
- 설정(스크립트에 들어 있음): A4 세로, 2단, 여백 1.5cm, 맑은 고딕, 본문 9pt, 제목 10pt 굵게. 표는 단 너비에 맞추고, 이미지는 단 너비 안.
- 확인: Word로 PDF를 내보내 몇 쪽을 렌더링해서 직접 본다. 수식이 많은 쪽, 그래프 쪽, 표 쪽을 고른다.
  - `python -I <skill>/scripts/docx2pdf.py "...docx" "<scratchpad>/preview.pdf"` (Windows는 Word, 그 밖은 LibreOffice. 둘 다 없으면 확인을 못 했다고 알린다)
  - `python -I <skill>/scripts/render_pages.py "<scratchpad>/preview.pdf" "<scratchpad>/pages" 12 14 31`

## 수식 (md2docx_math.py)

LaTeX(`$…$`, `$$…$$`)를 Word 수식(OMML)으로 바꿔 넣는다. Windows에 Office가 있으면 MathML → Office의 MML2OMML.XSL, 없으면(claude.ai 등) pandoc으로 바꾼다(`pip install pypandoc_binary`). Word 수식이므로 Word에서 바로 편집할 수 있다.

- 한 줄 전체가 `$$…$$`(불릿 포함) → 가운데 정렬 별도 수식 문단, 11pt. `- 설명: $$…$$`처럼 앞에 글이 있으면 설명 문단 + 아래 수식 문단으로 나눈다.
- 문장 속 `$…$` → 10pt. **문장 속 분수는 Word가 작게 줄이므로** 분자·분모 글자를 13pt로 키우고 분수 기준 크기를 본문에 맞춘다. 그래도 분수는 되도록 `$$` 줄로 세운다.
- 수식에도 문단 색(회색·빨강·파랑)·굵게·형광펜이 그대로 들어간다.
- Word 변환이 잃는 것을 스크립트가 바꿔 준다: 간격 명령(`\quad`, `\;`) → 공백, `\underbrace{식}_{설명}` → `식 (설명)`, `\underset{\downarrow}{i}` → `i↓`.
- 통화 `\$` → 글자 `$`.
- 수식 글자가 0x08 같은 제어 문자로 깨지면, 파이썬 문자열에서 `\b`·`\t`가 해석된 것이다. 파이썬으로 .md를 고칠 때는 raw 문자열(`r"\frac"`)을 쓰고, bash heredoc 안에 백슬래시가 든 파이썬 코드를 넣지 말고 파일로 써서 실행한다.

## 글자 색 (문단 단위, 스크립트가 표시를 보고 입힘)

| 내용 | .md 표시 | Word 글자 |
| --- | --- | --- |
| 일반 내용(강의자료) | 표시 없음 | 검정 #000000 |
| 강의에서만 언급한 추가 내용 | (자료에 없음) | 파랑 #0B57D0 |
| 강의 중 설명한 내용 | [강의] | 회색 #595959 |
| 교수가 강조한 내용 | [강의] (중요) | 빨강 #C00000 굵게 |
| 중요하지만 일상적인 강조 | **굵게** | 검정 굵게 |
| 문제풀이 때 추가한 내용 | [풀이] | 초록 #2E7D32 |

- 한 문단에 표시가 겹치면 빨강 > 파랑 > 회색 > 검정 순으로 하나만 적용. 색은 불릿 한 줄 단위로 들어가므로 [강의] 내용과 강의자료 내용을 한 불릿에 섞지 않는다.
- 머리말의 색 설명 줄처럼 표시 글자가 그대로 들어간 줄도 색이 입혀진다(예시로 보여 주는 효과).

## 형광펜

| .md 표시 | Word |
| --- | --- |
| `==키워드==` | 노랑 형광펜 |
| `==분홍:키워드==` | 연한 분홍 음영 #FADADD |
| `==파랑:키워드==` | 연한 파랑 음영 #D6E8FA |

## 불릿 · 그 밖

- 1단계 ▪, 2단계 ◦, 3단계 -.
- Mermaid 코드 블록은 "[도식: .md 파일에서 확인]"으로 들어간다. 다른 코드 블록(글자 트리)은 고정폭 글꼴.
- 열이 많은 표는 2단 폭에서 숫자가 줄바꿈된다(−49.7 → −49./7). 행·열을 바꿔 세로로 길게 만든다.

# 마인드맵 · 스터디 가이드 · 모의고사

세 결과물 모두 study note에 있는 내용만 쓴다(요약·재배열만). 항목마다 노트 절 번호를 단다(예: → 5.4.6). 사용자가 헷갈릴 때 노트 원문으로 바로 찾아갈 수 있게 하기 위해서다. 수식은 노트와 같은 LaTeX 규칙(`references/note-rules.md`의 "수식")을 따른다.

## 마인드맵 (키워드 구조도)

마인드맵은 방사형이 아니라 **왼쪽 상위 → 오른쪽 하위로 세분화되는 구조도**다. 목표는 **노트를 안 보고 마인드맵만 따라 읽어도 내용을 알 수 있는 것**이다.

### 라벨은 키워드 + 핵심 (가장 중요)

그림에는 상자 이름(라벨)만 보이고, 설명(d)은 마우스를 올려야 나온다. 그래서 라벨 자체가 뜻을 담아야 한다. "세 경우", "확실", "950", "두 항", "설명력", "예" 같은 라벨은 앞뒤 맥락 없이는 무슨 말인지 모른다는 지적을 받았다.

- 형식: `키워드: 핵심` 또는 `원인 → 결과`. 한 상자 약 25자 안팎.
  - 나쁨: `피셔효과` → `확실` / `불확실`
  - 좋음: `피셔효과: 기대인플레↑ → 금리↑` → `가격 확실히↓ · 금리↑` / `거래량 = 알 수 없음`
  - 좋음: `P > 액면 → YTM < 표면이자율`, `유동성 함정: 0%면 안 내려감`, `약간 하락 9→8%: 9.125% · 9.5% 여전히 우상향`
- 개념 하나를 **역할 가지**로 한두 단계 더 펼친다: 정의 / 공식 / 원인 / 결과 / 조건 / 숫자 / 예 / 함정 / 교수(강조한 말). 끝까지 내려가면 한 상자 = 한 사실이 된다.
- 공식은 라벨에 LaTeX로 쓴다: `"현재가치 $PV = \\dfrac{X}{(1+i)^n}$"`(파이썬 문자열이라 `\\`). 웹 페이지에서는 수식으로, .md(Mermaid)에서는 유니코드 첨자 글자로 바뀐다.
- 통화는 `\\$`.

### 위계를 짜는 법

- 노트 절 번호 순서가 아니라 **개념의 상하관계**로 짠다. 소제목 안에서도 상하관계를 뽑아낸다.
- **묶음(g)**: 노트가 "N요소·N가지·N사실"로 묶은 것은 부모에 묶음 이름(`3요인`)을 달고, 핵심 구성원은 번호 1) 2) 3)으로. 부모 라벨에 같은 말을 또 쓰지 않는다(`금융시장 4구분 〔4구분〕` ✗ → `금융시장 구분 〔4구분〕`).
- **보조 항목(a)**: 핵심이 아닌 형제(도구·근거·공식·함정·질문·계산·현실 등)는 태그를 달고 번호 없이 뒤에. 라벨에서 태그와 같은 말을 반복하지 않는다(`[함정] 함정: …` ✗).
- **예시는 `a="예"`로 표시**한다(레몬 시장 숫자, 사과 예, 특정 회사 계산 예). 프린트용에서 빠진다.
- 노트가 뭉뚱그린 묶음("6가지 요인")은 번호 붙은 하위 노드로 풀어 쓴다.

### 노드에 담는 것

- 라벨(t): 위의 키워드 형식. (중요) 개념은 key=True(★).
- 설명(d): 보통 비워 둔다(라벨이 이미 내용을 담음). 필요하면 한 줄.
- **결론(z)**: 끝 노드에 "그래서 무엇"을 붙인다(숫자·결론·교수 말). 그림에서 회색 점선 상자로 보인다.
- 근거 절(r): 노드마다 노트 절 번호. 웹 페이지에서 누르면 그 절 원문이 펼쳐진다.

### 만드는 방법

- 개념 트리를 데이터 파일(과목 폴더 `tools/concepts_vN.py`)로 쓰고 빌드한다. 노드 작성법은 `scripts/structure/structure_model.py`의 `N(라벨, 설명, [근거 절], key, kids, z, g, a)`.
- 웹 페이지 묶음과 함께 만들 때(권장): `scripts/web/build_web.py --concepts tools/concepts_vN.py --mindmap-md "{…}_마인드맵_vN.md"` (`references/web.md`). 마인드맵 웹 페이지·.md·프린트용 HTML이 한 번에 나온다(`scripts/structure/mindmap_build.py`).
- .md만: `scripts/structure/build_structure.py --note … --concepts … --html … --md …` (라벨에 LaTeX가 없을 때).
- 빌드는 근거 절이 노트에 없으면 멈춘다. 노트 목차를 먼저 확정하고, 노트 절을 옮기면 concepts의 근거 절도 고친다.
- **.md**: 장마다 Mermaid `flowchart LR` + 글자 트리(├─ └─). 글자 트리에는 모든 노드·결론·근거 절을 넣는다(Ctrl+F용).
- 강의 간 연결(LINKS)은 노트에서 연결이 확인되는 것만.
- 구조도를 고칠 때 원래 파일은 지우지 않고 새 버전(v2, v3…)으로 만든다.

### 프린트용 마인드맵 (A3)

사용자가 프린트해서 옆 빈칸에 써 가며 외우는 용도다. 빌드가 `web/mindmap_print.html`을 만들고 `scripts/browser.py pdf`로 PDF를 만든다(브라우저가 없으면 HTML을 넘겨 사용자가 인쇄).
- A3 가로 한 쪽을 세로 4칸(105mm)으로: **내용 | 빈칸 | 내용 | 빈칸**. 내용 칸 옆은 항상 빈칸이다.
- 회색 결론 상자(z)와 예시 가지(a="예")는 뺀다.
- 가지(부모 + 아래 전부)는 한 칸에 통째로 둔다. 안 들어가면 그 가지를 다음 칸으로 보내고, 한 칸보다 큰 가지만 나눠 다음 칸 위에 부모 이름을 "(계속)"으로 다시 적는다. 장(대제목)은 새 쪽에서 시작한다.
- 칸마다 남는 높이는 노드 사이 간격을 넓혀 채운다(글자 크기는 모든 쪽이 같다).
- 사용자가 다른 배치(A4, 칸 수, 장당 1쪽)를 원하면 `mindmap_build.py`의 PRINT_CSS·PACK_JS를 고친다. 바꾼 배치는 PDF로 한 번 그려 확인한다.

## 스터디 가이드

- 목표: 시험 직전 이 파일 하나로 범위 전체를 복습. **교재(슬라이드) 내용을 충실히 담고**, 교수 말은 따로 표시한다. 교수 강조만 모으면 교재의 정의·목록·공식이 빠졌다는 지적을 받았다.
- .md + .docx + 웹 페이지(색·형광펜이 보이도록).

### 구성 (장 순서, 장마다 같은 틀)

머리말: 시험 범위·예상 형식, 색 표시 설명(검정 = 교재, [필기]·[판서], 회색 [강의], 빨강 [강의] (중요), 파랑 (자료에 없음), 형광펜 3색).

장마다:
1. **📘 교재 핵심** — 그 장의 정의, 목록(예: 상품 n개, 규제 n가지, 사실 n개 × 이론 n개 표), 공식(`$$` 줄), 표, 핵심 그래프 그림 1~2개와 그 그림의 움직임 요약, 슬라이드 계산 예와 [풀이].
2. **🎙 교수 강조** — [강의] (중요) 줄(빨강), [강의] 줄(회색), 강조한 말 따옴표, 노트 절 번호.
3. **⚠ 함정** — 헷갈리는 쌍(==분홍== ↔ ==파랑==), 자주 틀리는 계산 포인트.

뒤쪽 모음: 헷갈리는 개념 비교표 / 공식 모음 표(LaTeX) / 숫자 모음 표 / 시험 형식별 답안 요령 / 시험 직전 체크리스트(`- [ ]`).

### 가독성

- 불릿 위주, 한 줄 약 40자 안팎, 3단계까지.
- 흐름 `A → B → C`, 구조는 트리, 비교는 표. 표 칸이 좁아지는 넓은 표(열 6개 이상)는 행·열을 바꿔 세로로 길게.
- Word 수식에서 무너지는 `\underbrace` 대신 식 + 아래 한 줄 설명을 쓴다.
- 교수가 비중을 낮춘 내용은 한 줄로 줄이고 그 말을 함께 적는다.

## 모의고사

- 별도 파일({…}_모의고사.md) + .docx + 웹 페이지(정답·풀이를 하나씩 펼쳐 보는 형식).
- 정리 노트에 있는 내용만으로 출제한다. 노트의 원리를 적용해 숫자를 새로 만든 문제는 `[응용 계산]`, 노트에 없는 설정(예: 직선 수요·공급식)을 쓰면 `(자료에 없음)`을 붙인다.
- 형식과 비중은 시험 정보를 따른다. "계산이 많다", "기간별 계산"이라는 정보가 있으면 계산 문제를 절반 가까이 두고, **1기·2기·3기처럼 시점이 이어지는 문제**(금리 변화에 따른 기간별 가격·수익률, 기간별 기대금리 등)를 여러 개 넣는다. 정보가 없어도 OX·단답·계산·그래프·서술을 고루 둔다.
- 교수가 강조한 부분에서 낸 문제는 (중요).
- **모든 숫자는 파이썬으로 다시 계산해 확인한다.** 중간값(각 항의 값)도 맞춰 적는다.

### 문제 형식 (웹 페이지가 이 형식을 읽음)

```
## Ⅲ. 계산 (28문항)          ← 대제목에 OX·단답·빈칸·객관식·계산·그래프·서술 중 하나를 넣으면 거르기 버튼이 생김
### Ⅲ-1. 현재가치·YTM        ← 소제목(선택)

**21.** (중요) [응용 계산] 문제 글

- 정답: 짧은 답
- 풀이:
  - $$PV = \frac{1{,}210}{(1.10)^2} = 1{,}000$$
  - 단계 설명 한 줄
- 관련 설명: 이 문제가 묻는 개념, 교수 강조, 비슷한 슬라이드 예 (1~3줄)
- 채점 포인트: ① … ② … (서술형·그래프)
- 노트: (→ 2.2.2, 2.3)
```

- 정답·풀이·관련 설명·노트는 모든 문제에 단다. OX도 왜 O/X인지 풀이를 쓴다.
- 서술형·그래프는 모범 답안(정답·풀이)과 함께 **채점 포인트**를 적는다. 조건 하나를 빠뜨려 크게 감점되는 일을 막기 위해서다.
- 노트 밖 설명을 덧붙여야 하면 [풀이] 표시.
- 계산식은 `$$` 줄로, 분수는 `\frac`.
